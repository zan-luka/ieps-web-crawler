# How to use
1. Clone the repository `git clone https://github.com/zan-luka/ieps-web-crawler`
2. Create a virtual environment
3. Install ollama from https://ollama.com/
4. Install the models
```bash
ollama pull gemma3:4b
ollama pull hf.co/tknez/GaMS-9B-Instruct-GGUF:Q6_K
```
5. Install dependencies from requirements.txt

# To run
- Run main.py
- Go to http://localhost:8000/
